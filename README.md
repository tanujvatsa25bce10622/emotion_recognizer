# Real-Time Emotion Recognition System

## Description

This project is a Python-based application that performs real-time emotion detection using a webcam. It leverages computer vision and deep learning techniques to analyze facial expressions and classify emotions.

The system uses the DeepFace library for emotion recognition and OpenCV for video capture and display.

---

## Features

- Real-time emotion detection from webcam input
- Facial expression analysis using deep learning
- Display of dominant emotion on live video feed
- Simple and efficient implementation

---

## Tech Stack

- Python
- OpenCV
- DeepFace
- TensorFlow

## How To Run

python main.py
